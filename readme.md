# 🐄 Умная Ферма AI

Интеллектуальная система видеоаналитики для мониторинга крупного рогатого скота (КРС).
Система распознаёт активность животных (кормление / водопой), анализирует фазы сна и покоя, а также оценивает упитанность (БКС/КВС) по видеопотоку с камер, используя модели YOLOv8.

**Разработка:** студенты группы ИСТ-418Б — Гафаров Мурат Радикович, Еременко Станислав Викторович, Закирова Рената Винеровна.

## 1. Что нужно установить перед началом

Перед установкой самого проекта на компьютере должны быть установлены две программы:

| Программа | Версия | Зачем нужна | Где скачать |
|---|---|---|---|
| **Python** | 3.11 или новее | На нём написан весь проект | [python.org/downloads](https://www.python.org/downloads/) |
| **PostgreSQL** | 14 или новее | База данных, где хранятся коровы, камеры, отчёты и т.д. | [postgresql.org/download](https://www.postgresql.org/download/) |
| **Git** | любая современная | Чтобы скачать (клонировать) код проекта | [git-scm.com/downloads](https://git-scm.com/downloads) |

> ⚠️ **Важно при установке Python (Windows):** в первом окне установщика обязательно поставьте галочку **"Add Python to PATH"** — иначе команды `python` и `pip` не будут работать в терминале.

> ⚠️ **Важно при установке PostgreSQL:** установщик попросит задать пароль для пользователя `postgres`. **Запомните этот пароль** — он понадобится при первом запуске программы.

Проверить, что всё установилось, можно, открыв терминал (`cmd` или PowerShell в Windows) и выполнив:

```bash
python --version
git --version
```

Обе команды должны вывести номер версии, а не ошибку.

## 2. Установка проекта — шаг за шагом

### Шаг 1. Скачать код проекта

Откройте терминал в удобной папке (например, на Рабочем столе) и выполните:

```bash
git clone -b dev https://github.com/mura102/diplom_cow_tracking.git
cd diplom_cow_tracking
```

> Ветка `dev` — рабочая (актуальная) ветка проекта, поэтому клонируем именно её через флаг `-b dev`.

### Шаг 2. Создать виртуальное окружение

Виртуальное окружение — это изолированное "пространство" для библиотек проекта, чтобы они не конфликтовали с другими программами на компьютере.

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
```

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

Если всё прошло успешно, в начале строки терминала появится приставка `(.venv)`.

### Шаг 3. Установить зависимости

```bash
pip install -r requirements.txt
```

Эта команда установит все необходимые библиотеки: PyQt6 (интерфейс), Ultralytics YOLOv8 и PyTorch (нейросети для детекции), OpenCV (обработка видео), SQLAlchemy и psycopg2 (работа с базой данных), ReportLab и openpyxl (отчёты) и т.д.

> ⏳ Установка может занять от 5 до 15 минут — библиотека `torch` (PyTorch) весит несколько гигабайт.

> 💡 Если pip выдаёт ошибку кодировки при чтении `requirements.txt` — файл сохранён в кодировке UTF-16, попробуйте команду `pip install -r requirements.txt --no-cache-dir`, либо откройте файл в блокноте/VS Code и пересохраните его в UTF-8.

### Шаг 4. Настроить подключение к базе данных

В корне проекта нужно создать файл `.env` (без расширения, начинается прямо с точки) со следующим содержимым:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=cow_tracking_db
DB_USER=postgres
DB_PASSWORD=пароль_который_вы_задали_при_установке_postgresql
```

> ⚠️ Файл `.env` не хранится в репозитории (он в `.gitignore`) — его нужно создать самостоятельно один раз на каждом компьютере.
>
> 💡 На самом деле этот шаг можно пропустить: при первом запуске (см. раздел 3) программа сама спросит пароль от PostgreSQL и сохранит его в `.env` автоматически.

## 3. Первый запуск и настройка базы данных

После установки зависимостей запустите программу:

**Windows (через терминал):**
```bash
python main.py
```

**Или просто дважды кликните файл `run.bat`** — он сам создаст виртуальное окружение при необходимости, установит зависимости и запустит программу.

**PowerShell:**
```powershell
.\run.ps1
```

### Что происходит при первом запуске

1. Программа проверяет, задан ли пароль от PostgreSQL в `.env`.
2. Если пароль не задан или неверный — появится диалоговое окно с просьбой ввести пароль пользователя `postgres` (тот, что вы задали при установке PostgreSQL).
3. После ввода правильного пароля программа **автоматически**:
   - создаёт базу данных `cow_tracking_db` (если её ещё нет);
   - создаёт все необходимые таблицы;
   - сохраняет пароль в `.env`, чтобы не спрашивать его при следующих запусках.
4. Появится окно авторизации — нужно войти под одной из ролей (см. раздел 4).

Никаких SQL-скриптов запускать вручную не требуется — база данных настраивается сама при первом старте.

## 6. Функциональные модули

- **📺 Мониторинг** — главная страница с карточками статистики (коровы в базе, события, тревоги), видеопотоком и результатами трёх независимых алгоритмов анализа.
- **🍽️ Детекция активности** — определяет по видео, ест или пьёт корова; результаты пишутся в базу данных.
- **🌙 Детекция сна** — определяет, лежит или стоит корова, фиксирует периоды отдыха и сна.
- **📊 Расчёт БКС/КВС** — оценка упитанности по шкале 1–5 с распознаванием ID животного по бирке; поддерживает фото и видео.

## 7. Возможные проблемы при установке

| Проблема | Решение |
|---|---|
| `'python' is not recognized as an internal or external command` | Python не добавлен в PATH — переустановите Python с галочкой "Add to PATH". |
| Программа выдаёт «Не удалось подключиться к базе данных» | Проверьте, что служба PostgreSQL запущена (Windows: `services.msc` → PostgreSQL), и что пароль в `.env` совпадает с паролем пользователя `postgres`. |
| Долгая установка `torch` / зависает pip | Это нормально — библиотека весит несколько гигабайт. Проверьте интернет-соединение и не прерывайте установку. |
| Ошибка при чтении `requirements.txt` | Файл в кодировке UTF-16 — пересохраните его в UTF-8 (в VS Code: внизу справа кликнуть на кодировку → "Save with Encoding" → UTF-8). |
| PyQt6 не открывает окно (Linux) | Установите системные пакеты Qt: `sudo apt install libxcb-cursor0` (Ubuntu/Debian) и убедитесь, что запущена графическая сессия X11 или Wayland. |
| Окно программы открылось, но нет видео с камер | Убедитесь, что камеры подключены и указаны верные источники видео (пути к файлам или индексы устройств) в соответствующих разделах интерфейса. |
